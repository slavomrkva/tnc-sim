Corrected program · Issue #44

Repeated contour with RL and CHF

This case exposed a simulator error: after the first plunge, radius compensation incorrectly discarded the contour. The simulator fix handles an intentional retrace of an earlier edge. The program below is the revised version supplied for publication.

What changed

The revised program keeps the tool call before activating RL and removes the later spindle and coolant commands from the compensated contour. The repeated L Y+95 remains in the supplied program; the second occurrence is a no-op. The displayed &#x20; in the pasted report was an HTML space entity and is represented as ordinary spacing in the downloadable file.

In the current web branch, validation and parsing complete without errors and produce contours at Z −5, −10, −15, −20, −25 and −31. Check the path and machining conditions on your own control before using any NC program.

Try it in TNC Sim

  1. Download the .H file above.
  2. Open the simulator and choose Import in the editor.
  3. Select the downloaded file, then run or step through the program.

Importing a file is a deliberate action: opening this page does not replace the program currently in your editor.

Program

BEGIN PGM PROGRAM MM
BLK FORM 0.1 Z X+0 Y+0 Z-31
BLK FORM 0.2 X+75 Y+75 Z+0
TOOL CALL 1 Z S10000 F2000
TOOL DEF 5 ; Pre-load tool in magazine for next TOOL CALL
Q41 = -5
LBL 1
L X-20 Y-20 FMAX M13
L Z+20 FMAX
L Z+Q41 F400
L X+0 RL
L Y+75
CHF 3
L X+75
CHF 3
L Y-0
CHF 3
L X+0
CHF 3
L Y+95
L Y+95
L Z+20 R0
LBL 0
Q41 = -10
CALL LBL 1
Q41 = -15
CALL LBL 1
Q41 = -20
CALL LBL 1
Q41 = -25
CALL LBL 1
Q41 = -31
CALL LBL 1
END PGM PROGRAM MM
