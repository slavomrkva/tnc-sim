Präzisionsbohrung — zentrieren, bohren, reiben (Zyklus 201)

Baue eine realistische Mehrwerkzeug-Bearbeitung auf: zentrieren, unter Maß bohren und die Bohrung mit einer Reibahle fertigstellen.

Interaktive Lektion starten Beispiel ansehen

Das lernst du

  • Zentriere vor dem Bohren auf volle Tiefe.
  • Lasse ein geeignetes Aufmaß für die Reibahle stehen.
  • Definiere Reibtiefe, Vorschub und Rückzug mit Zyklus 201.
Im echten Editor üben

Die interaktive Lektion öffnet sich in TNC Sim, prüft deine Klartext-Sätze und zeigt das Ergebnis in der 3D-Ansicht.

So funktioniert es

Eine geriebene Präzisionsbohrung entsteht üblicherweise in mehreren Stufen. Zentrieren sichert die Lage, Bohren erzeugt die Untermaßbohrung und Reiben fertigt Durchmesser und Oberfläche.

Zyklus 201 speichert die unterstützten Bewegungs- und Vorschubparameter zum Reiben. Dieselben Bohrungspositionen können über die Werkzeugwechsel hinweg wiederverwendet werden.

Klartext-Beispiel

Probiere die wichtigsten Sätze aus

Dieses kompakte Beispiel führt in das Thema ein. Die vollständige, geprüfte Aufgabe findest du in der geführten Übung.

TOOL CALL 6 Z S1200 F200
M3
CYCL DEF 201 ; Reaming
 Q200=+2   ; safety clearance
 Q201=-20  ; depth
 Q206=+200 ; reaming feed
 Q211=+0   ; dwell at bottom
 Q208=+500 ; retraction feed
 Q203=+0   ; surface coordinate
 Q204=+50  ; second safety clearance
L X+30 Y+30 FMAX M99
