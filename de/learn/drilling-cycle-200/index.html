Bohren — CYCL DEF 200 + M99

Definiere eine Bohrbearbeitung einmal über Zyklusparameter und verwende sie anschließend an einer oder mehreren XY-Positionen.

Interaktive Lektion starten Beispiel ansehen

Das lernst du

  • Lege Sicherheitsabstand, Tiefe, Vorschub und Zustelltiefe fest.
  • Definiere Werkstückoberkante und zweiten Sicherheitsabstand.
  • Rufe den aktiven Zyklus an einer Position mit M99 auf.
Im echten Editor üben

Die interaktive Lektion öffnet sich in TNC Sim, prüft deine Klartext-Sätze und zeigt das Ergebnis in der 3D-Ansicht.

So funktioniert es

CYCL DEF 200 speichert einen Bohrzyklus. Seine Q-Parameter beschreiben die Z-Bewegung und das Vorschubverhalten, während ein späterer Positioniersatz die Bohrungskoordinaten liefert.

M99 ruft den aktiven Zyklus an der programmierten Position auf. Dadurch bleiben wiederverwendbare Prozessdaten von der Liste der Bohrungspositionen getrennt.

Klartext-Beispiel

Probiere die wichtigsten Sätze aus

Dieses kompakte Beispiel führt in das Thema ein. Die vollständige, geprüfte Aufgabe findest du in der geführten Übung.

CYCL DEF 200 ; Drilling
 Q200=+2   ; safety clearance
 Q201=-15  ; depth
 Q206=+150 ; plunge feed
 Q202=+5   ; pecking depth
 Q210=+0   ; dwell at top
 Q203=+0   ; surface coordinate
 Q204=+50  ; second safety clearance
 Q211=+0   ; dwell at bottom
L X+30 Y+30 FMAX M99
