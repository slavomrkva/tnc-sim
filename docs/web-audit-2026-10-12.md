The full set of **50 Node test files passes**, including
`tests/web-audit-2026.test.js` and `tests/web-audit-runtime.test.js`.
Tracked JavaScript syntax checks and `git diff --check` also pass.

Run the same tests as web CI from the repository root:

```bash
for test_file in tests/*.test.js tests/*.test.mjs; do
  node "$test_file" || exit 1
done
```

The resource guard remains synchronous but rejects excessive cycle requests
before allocation. This change does not introduce a cancellable parser worker.
The 0.01 mm bound describes the polygonal XY path, not finished-part tolerance;
voxel stock and contact checks retain their resolution limits.

## Manual acceptance before merge

Serve this branch as the static site described in README.md (for example
`python3 -m http.server 8000`) and open the local site. Confirm v0.949.
No production preview URL is asserted by this document.

- [ ] Desktop Chrome/Firefox: Run, Step, M0 resume, tool change, Reset and Learn
      open normally; no uncaught console exceptions.
- [ ] Step to pause, edit X or tool radius, Run: valid changes restart from the
      beginning with fresh stock. An invalid edit blocks Run. A clean pause
      continues from its existing position.
- [ ] Run the primary demo and a known shop program in 3D. Inspect cycles
      200/201/208/209, RL/RR, tool changes and Refine at normal/high quality.
- [ ] Run a feed move after M5 through stock: it must leave stock intact;
      automatic/manual Refine must preserve the same uncut region. Verify a
      normal M3/M4 cut still removes material.
- [ ] Traverse stock horizontally and diagonally upward in FMAX: warn while
      continuing playback. Check a cleared-hole retract for excessive warnings
      at the chosen voxel resolution.
- [ ] Disable WebGL in an isolated test browser: editor, XY Run/Step and Learn
      must remain usable; 3D measure/refine controls must not throw.
- [ ] Use Tab then Enter/Space on XY Toolpath and Tool Table. Verify focus and
      selected state in both themes and narrow/short web viewport layouts.
- [ ] Refresh online once, then verify the cached web app opens offline with
      matching runtime assets (service-worker cache v114).

Browser/GPU visual checks were **not completed in the repair environment**:
the local browser binary download failed and the remote browser could not
connect to the local test server. VM tests cover behavior, not GPU rendering
or physical mobile touch interaction. Keep the PR in draft until the checks
above are accepted.
